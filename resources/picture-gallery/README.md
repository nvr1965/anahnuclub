# Drawn pictures for members

Profile pictures (`avatars/*.png`, 400×400) and profile covers (`covers/*.jpg`, 1640×624) that members can pick
in their profile, next to the club authors' own pictures in `resources/club-authors`.

They were drawn for AnahnuClub from plain shapes (circles, rectangles, paths), with no third party artwork,
in the same flat style as the club authors' pictures, and are released into the public domain under
**CC0 1.0 Universal**: https://creativecommons.org/publicdomain/zero/1.0/

To add a picture, drop a file of that size into the folder: it shows up in the profile picker by itself.
