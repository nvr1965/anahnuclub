# AnahnuClub: правила для ИИ-помощников

Этот файл читают и Codex (AGENTS.md), и Claude Code (через CLAUDE.md). Общие правила проекта пишем только сюда.

## Проект

Сайт сообщества anahnu.club, замена Joomla 3 + JomSocial.
Laravel 12 (PHP 8.3+) + PostgreSQL + React через Inertia (TypeScript, Tailwind).

- `app/` — бэкенд Laravel: `Http/Controllers`, `Models`, `Jobs`, `Translation` (цепочка переводчиков), `Moderation`, `Feeds`.
- `resources/js/` — фронтенд: `pages` (страницы Inertia), `components`, `layouts`, `hooks`, `lib`.
- `lang/{ru,he,en,ar}.json` — строки интерфейса, ключ — английский текст. `lang/{код}/*.php` — сообщения Laravel.
- `database/migrations`, `tests/Feature`, `tests/Unit`.
- `deploy/` — скрипты для SiteGround и тестовой виртуалки.

## Команды

```bash
composer install && npm install
composer dev                 # сервер, очередь и Vite
./vendor/bin/phpunit         # тесты (как в CI)
vendor/bin/pint              # формат PHP
npm run format && npm run lint
npm run build                # сборка фронтенда, должна проходить без ошибок
```

Перед коммитом прогоняйте тесты и линтеры для того, что меняли.

## Правила

- **Ветка `main` = продакшен.** Каждый push в `main` автоматически собирается и выкладывается на SiteGround. Работайте в отдельной ветке и через PR, в `main` напрямую не пушьте.
- Языки: ru, he, en, ar. Иврит и арабский — справа налево. Любая новая строка интерфейса добавляется во все четыре `lang/*.json`, вёрстка проверяется в RTL (используйте логические классы Tailwind: `ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`).
- Изменения схемы базы — только новой миграцией, старые миграции не редактируйте.
- Не коммитьте `.env`, ключи и дампы базы.
- Сообщения коммитов и описания PR — коротко и по делу; общение с владельцем — на русском.

## Совместная работа Claude Code и Codex

- Основной инструмент — Claude Code. Codex подключён к нему как MCP-сервер (`codex mcp-server`) и используется для второго мнения: ревью изменений, поиск ошибок, альтернативное решение.
- Если просят «проверь через Codex», передайте Codex дифф или список файлов и задачу ревью; его замечания проверьте сами, прежде чем применять.
- Оба помощника работают в одной папке, поэтому не запускайте их одновременно на одних и тех же файлах.
